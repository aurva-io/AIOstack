User management in AIOStack is handled from the Aurva console at [app.aurva.ai](https://app.aurva.ai).

## Inviting users

::steps
### Open Settings

Click your account icon in the **bottom left** of the console, then select **Settings**.

### Go to User Management

In the Settings sidebar, select **User Management**.

### Send an invite

Click **Invite Users**, enter the email address of the person you want to add, and confirm. An invitation email is sent immediately.

### User accepts the invite

The invited user receives an email with a joining link. Clicking the link takes them to a page where they can set their password and complete account setup. Once done, they'll have access to the console.
::

## Managing existing users

From the User Management page you can:

- **View** all active users and their current status
- **Resend** an invite if a user hasn't accepted yet
- **Revoke** access for a user who should no longer have it

## Coming soon

More user management capabilities are on the roadmap, including **role-based access control (RBAC)** to assign different permission levels across team members. If you have specific access control requirements in the meantime, reach out to your Aurva support representative or contact [support@aurva.io](mailto:support@aurva.io).

## Notes

- Invitations expire after a period of time. If a user reports their link is no longer valid, resend the invite from User Management.
- Users set their own password when accepting the invite — passwords are not set or shared by admins.
- If your organization uses SSO, contact [support@aurva.io](mailto:support@aurva.io) to discuss enterprise authentication options.
